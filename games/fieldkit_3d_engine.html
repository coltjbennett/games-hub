BUILD A GAME FROM THIS FILE

This file is the engine and the game at once. Copy it, rename it, and edit it in place. Everything (rendering, physics, input, camera, character, vehicle, UI, textures, audio) is plain source in this one file. The only external code is Three.js and cannon-es, loaded from a CDN in the LIBRARIES block at the top of the script (swap in local copies there if you want it fully offline).

MAP OF THE SOURCE

  • GAME_CONFIG — all the knobs: physics rate, gravity, player, camera, lighting.
  • Engine — renderer, fixed-step physics with interpolation, entities, raycasts, triggers, events, adaptive resolution.
  • Input — action bindings for keyboard, mouse, touch, gamepad. Games ask for input.isDown('jump'), never for raw keys.
  • CharacterMotor — the on-foot physics (hover capsule). PlayerController wires it to input, camera and avatar.
  • CameraRig — first / third person, collision-safe spring arm, shake, and an override hook for cutscenes or vehicles.
  • GrabSystem — springy (hold) and rigid (toggle) pickup, throw, push.
  • VehicleController — raycast car with chase camera. Atmosphere — sky, lights, fog, shadows, reflections.
  • EDIT ZONE: WORLD and EDIT ZONE: GAMEPLAY near the bottom — the only parts you must replace. DebugUI (tuning panel) is optional; delete it for a shipping game.

RECIPES

// Platformer: tighter, floatier jump, third-person camera
player.motor.jumpSpeed = 7.2; player.motor.fallGravityScale = 1.6;
player.motor.airAcceleration = 40;

// FPS: first person + hitscan weapon
player.camera.setMode('first');
input.onPress('primary', () => {
  const o = new THREE.Vector3(), d = new THREE.Vector3();
  player.camera.getAimRay(o, d);
  const hit = engine.raycast(o, d, 200);
  if (hit?.entity) hit.entity.body.applyImpulse(
    new CANNON.Vec3(d.x*8, d.y*8, d.z*8), hit.point);
});

// Racing: drive from the start
const car = new VehicleController(engine, { position: [0, 1, 0] });
car.enter(player);

// Custom action + key
input.rebind('dash', ['KeyC']);
input.onPress('dash', () => { player.motor.body.velocity.x += 8; });

// Triggers, events, per-frame entity logic
engine.addTrigger({ position:[0,1,0], size:[3,3,3], onEnter: e => toast('hi') });
crate.onUpdate = (dt, entity) => { entity.mesh.rotation.y += dt; };
engine.events.on('reset', () => {});

HONEST LIMITS

This is a strong starting engine, not Unreal. Physics is cannon-es (fine for hundreds of bodies, not thousands). There are no skeletal animations, networking, or streaming for huge worlds. The character is a hover capsule that handles steps, slopes, moving platforms and pushing props; swimming, ladders and wall-running are yours to add on CharacterMotor.
