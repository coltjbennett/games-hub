FIELDKIT ENGINE API

This file is intentionally a small framework plus a playable example. Keep the GameEngine, InputManager, and reusable helper methods; replace the buildDemoWorld(engine) section with your own level and systems.

// Create an engine
const engine = new GameKit.GameEngine({ canvas, gravity: -9.82 });

// Add physical objects (size is full dimensions)
const crate = engine.addBox({
  position: [2, 2, 0], size: [1, 1, 1], mass: 3,
  color: 0x8df5c6, friction: 0.65, restitution: 0.08
});

// Add game systems
engine.onFixedUpdate((dt) => { /* deterministic game logic */ });
engine.onUpdate((dt) => { /* visuals, UI, interpolation-safe logic */ });
engine.start();

Included: fixed-step physics, gravity, box/sphere collisions, material friction/restitution, sleeping, body-mesh syncing and interpolation, character motor with ground detection, jump/sprint, pointer lock, mouse drag fallback, touch joystick, multi-pointer look/buttons, runtime sliders, resize handling, and reset/spawn helpers.

Reuse notes: meshes created outside the helpers can be paired with any Cannon body by calling engine.bindBody(body, mesh). Register systems with onFixedUpdate or onUpdate. You can read engine.input.isDown('Space'), engine.input.getMoveAxes(), and change engine.world.gravity.y. Public classes are exposed at window.GameKit.

Physics is provided by Cannon-es, not a full character-controller/capsule solver. The example controller uses a fixed-rotation box collider for predictable, fast movement. For production-sized worlds, add level streaming, spatial audio, pooling and a more specialized character controller as your game needs grow.
