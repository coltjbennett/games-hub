GAMES HUB — CHANGELOG
=====================

2026-09-30 — v4.0.0 — Desktop upgrade, convenience features & resilience

• Added Control Panel applet with theme switching, CRT/motion/compact/high-contrast controls, install-as-app action, and safe interface reset.
• Added System Monitor applet with live FPS, viewport/DPR, browser capability, network, JS heap, and Storage API telemetry.
• Added Timer applet with presets, custom durations, pause/reset, and optional completion sound.
• Added Quick Launch command palette (Ctrl+K or /) covering applets, site sections, and every cataloged game.
• Added persistent project favorites, recent-project history, one-click copy-link actions, and quick library filters.
• Added live online/offline indicator and a global toast notification layer for launcher feedback.
• Added PWA manifest, install prompt handling, service-worker caching, and an offline landing page for better repeat loads and weak-network behavior.
• Added appearance presets (classic, graphite, midnight mint), reduced-motion mode, compact mode, and high-contrast mode.
• Added more taskbar/start-menu entries for the new utility suite.
• Added cache-aware Arcade Hub directory snapshots so temporary GitHub API failures can fall back to the most recent known listing.
• Added generated PWA launcher icons based on the existing site icon.
• Updated project-library controls to clear search/status/history views without reloading the site.
• Added additional keyboard and accessibility affordances around the new quick-launch surface.
• Added a visible MQTT connection-state indicator in Chat so connecting/reconnecting/offline states are distinguishable from an idle room.
• Fixed the Gang Wars home link so it correctly returns to the launcher from the games directory.

2026-09-30 — Maintenance & hardening

• Added an in-site changelog viewer to the homepage footer.
• Added the Web Browser to the homepage Applets taskbar.
• Kept makedata.html as a direct-link-only utility; it is not exposed in the homepage taskbar.
• Removed the tiled background and CRT treatment from Notes and restored a normal Windows-gray workspace.
• Reworked Calculator toward a classic Windows 95-era calculator appearance and removed dynamic JavaScript expression evaluation.
• Hardened the game library against malformed repository metadata and unsafe game URLs.
• Encoded repository path segments in Arcade Hub asset/game URLs for safer handling of unusual filenames.
• Hardened same-origin cross-frame messaging between the shell, Arcade Hub, and Chat.
• Reworked security-sensitive chat UI paths to avoid interpolating network usernames into executable event-handler HTML.
• Added chat payload validation, plain-text length limits, and strict local media-data URL checks to reduce malformed state and accidental lag.
• Hardened generic file attachments while retaining ordinary downloadable file types.
• Tightened the web browser applet's URL parsing and blocked embedded credentials.
• Added additional defensive browser-storage handling where practical without introducing a server.

Architecture note
-----------------
Games Hub remains intentionally serverless and continues to use GitHub Pages, browser storage, and its existing realtime transport architecture.
The client-side admin access mechanism is intentionally unchanged.
