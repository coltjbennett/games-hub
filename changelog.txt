2026-10-29 - v4.4.0 - Tapey, achievements, widgets, save slots and a pile of classics

• Tapey, a roll of tape with cartoony eyes, now lives on the desktop. 20 poses (128x128 SVGs in images/tapey), eyes that follow your cursor (even inside apps and games), blinking, sleeping when idle, dancing, and cross-eyed when you get too close. He is context-aware: time of day, day of week and holidays, which apps and games you open, how long you have been here, achievements, window count, network and battery. Almost 1,900 lines of dialog live in images/tapey-dialogs.js and images/tapey-dialogs-more.js. Five personalities (Classic, Sassy, Friendly, Nerdy, Quiet). Click him and type: he can do quick math, open apps, launch games, flip coins, roll dice, tell jokes, tips and facts, search help topics, answer small talk and change his own settings. Tapey Settings (Accessories) covers size, opacity, tape color, mirror, balloon style, text size, eye strength and smoothing, sleep timing, chattiness, topics, sounds and more.
• Achievements: 52 trophies (some hidden) with popups and an Achievements app; progress also shows as a widget.
• Desktop widgets (right-click the desktop): Clock, Calendar, Sticky Note, System, Progress, Lucky (random game) and Tip of the Day. Drag them anywhere; they remember their place.
• Save slots for the local games only (not the Chatroom, not the third-party Arcade Hub): a 💾 button in each game window opens 6 slots with Save, Load, Rename, Export, Import and Delete.
• Project Library: new 🎲 Random Game button (also in the Start menu, desktop menu, Tapey and a widget).
• More classic apps: File Manager, WordPad, Character Map, Calendar, Sound Recorder, Media Player, Phone Dialer, Disk Defragmenter, FreeCell and Reversi.
• Text Games (Games menu and MS-DOS: ADVENT, HANGMAN, GUESS, MADLIBS, SCRAMBLE, BLACKJACK).
• File system: new "file" type (WordPad documents, recordings, imported files), cut/copy/paste/duplicate/download, import files from your computer (menu or drag and drop), ZIP export and import, search with wildcards, and MS-DOS MD, RD, DEL, REN, COPY, MOVE and EDIT inside MYDOCS.
• MS-DOS Prompt: rewritten input so the on-screen keyboard no longer glitches or disappears on phones; on-screen Esc, arrow, Tab and Enter keys; Tab completion.
• Internet Explorer: new retro look (menu bar, big toolbar buttons, throbber, Links bar, status bar), Back/Forward/Stop/Refresh/Home, Favorites and History, typing words searches the web, and a ColtonNet start page (applets/ie-home.html).
• Sounds: the hard drive now plays only a spin-up (no clicks) and only when "Play sounds for windows" is on. Opening the Web Browser or Chatroom plays images/dial.mp3 for as long as the file lasts, and clicking the connection window skips it. ScanDisk plays the spin-up too.
• Boot: the CRT turn-on effect now plays at the very start of POST instead of before the Windows logo.
• Versioning: the service worker reads its version from data.js, and scripts/sync-version.js copies it into package.json (also run by the deploy workflow). data.js is now the only place to change the version.

2026-10-27 - v4.3.0 - ColtonOS gets a real file system, and acts like a computer

• Startup / shutdown: Start › Shut Down now plays a proper power-off (the picture collapses to a bright line and a fading dot). If you close the tab without shutting down, the next boot runs ScanDisk. New "Restart in MS-DOS mode" option opens a full-screen DOS prompt (type WIN or EXIT to come back).
• MS-DOS Prompt (Accessories): DIR lists your real games, CD moves between folders, and typing a game's name launches it. Also VER, HELP, CLS, TYPE, MEM, TREE, COLOR and a few easter eggs.
• Minesweeper and Solitaire, written from scratch with original art (Start › Programs › Games, Classic Games folder).
• Virtual file system stored in IndexedDB: My Documents, right-click New (Folder, Text Document, Bitmap Image) on the desktop and in folders, rename, delete, and drag desktop files onto folders to file them away.
• New Notepad applet creates, opens and saves .txt files into My Documents; Paint can now Open, Save and Save As pictures there too.
• Network Neighborhood lists the people currently in the chatroom as computers on the network.
• Theater: a synthesized hard-drive crunch and "Copying files…" dialog when a game launches, a dial-up modem screech when opening the Web Browser or Chatroom, hourglass cursor while busy, menu clicks, and an "illegal operation" dialog if a game crashes (with the real error under Details).
• Online counter in the taskbar tray.
• Your own tiled wallpaper: pick any image and a tile size; it is reduced to that preset automatically and saved in IndexedDB.
• Control Panel › Customize: desktop themes (color scheme + wallpaper + CRT + sounds in one click), icon name lines and spacing, outlined names, hidden icons, selection and title-bar colors, gradient title bars, window shadows, interface font, 24-hour clock with seconds, and toggles for every theater effect.
• Applets now live in their own `applets` list in data.js and are auto-detected (Accessories, Start menu, Find) without ever appearing in the Project Library. applets/makedata.html can generate both game and applet entries.
• Touchscreens can drag on empty desktop space to select multiple icons.
• Long desktop icon names are shortened with an ellipsis (selecting an icon shows the full name).
• Text files from the site (Changelog.txt and friends) now open in a viewer that forces black text on white with the site font, so they stay readable on dark-mode devices. Notepad does the same.
• Fixed System Monitor export/import: backups no longer depend on a downloaded ZIP library, and restoring no longer gets stuck waiting on the chatroom's open database.

2026-10-24 - v4.1.6 - Significant chatroom refactor

• Rebuilt chat storage on IndexedDB with one record per message, so only changed messages are written instead of rewriting the entire history, and attachments are stored as separate deduplicated Blobs. Existing history is migrated automatically.
• Attachments are now sent as hash-verified binary frames on their own topic, automatically broadcast to everyone and retroactively synced to users who are missing them. The attachment limit is now 20 MB.
• Added chat thumbnails and video poster frames, lazy media loading, and lossless EXIF/GPS metadata stripping for photos, with rotated photos redrawn upright.
• Images and videos now open in a lightbox with a Windows-style close button. Videos can also play inline, iPad .mov clips are supported, and right-click or long-press on media offers Download.
• Added image/file paste and drag-and-drop uploads, smaller voice memos, a click-to-load YouTube embed, and optional "Hide join/leave messages" and desktop-notification settings.
• DMs and sync traffic now use private per-user topics instead of the shared room topic, durable messages use a persistent broker session with an outbox that retries failed sends, and disconnected users are detected via MQTT Last Will.
• Sync is much quieter, with unicast responses, sampled responders, byte-sized packets, and a slow anti-entropy check instead of a minute-by-minute broadcast.
• The message list now reuses existing elements instead of rebuilding the whole chat, and search now covers the full stored history.
• Replaced all native alert, confirm, and prompt dialogs with styled modals, and message editing now uses a large Apply/Cancel editor.
• The GitHub chat-backup restore now runs only on first visit, with a new "Restore from GitHub Backup" button in settings.
• Added send rate limits and optional signed admin commands, fixed an injection hole in message buttons, and fixed numerous sync, mention, and media bugs.

2026-10-02 — v4.1.3 – Automatic service-worker updates & stale-cache recovery

• Added automatic service-worker update checks so the launcher can detect newly published versions without requiring users to manually clear Cache Storage.
• Added explicit service-worker update checks when the launcher tab opens.

• Added automatic activation of newly installed service workers so updates do not remain waiting behind an older active worker.
• Added automatic client takeover through service-worker client claiming so updated workers can begin controlling existing launcher tabs immediately.
• Added automatic page reload handling when a newly updated service worker takes control, ensuring the current tab switches to the updated application code.
• Added service-worker cache bypass behavior for update checks so stale HTTP-cached service-worker scripts cannot prevent update detection.
• Bumped the application cache generation so obsolete cache generations are automatically removed when the new service worker activates.
• Improved stale-cache recovery for users who were previously locked onto older cached launcher versions.
• Changed normal application-resource loading to prefer the current live site when online, using Cache Storage as an offline fallback instead of treating the cache as the primary source.
• Added automatic cache refreshes from successful live responses so cached resources stay synchronized with the currently published site.
• Preserved offline functionality by continuing to serve previously cached resources when the live site cannot be reached.
• Removed the need for users to manually open System Monitor and clear Cache Storage to receive future launcher updates.
• Improved update resilience for returning users by allowing the existing service-worker installation to migrate itself to the current launcher version.
