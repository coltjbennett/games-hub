2026-10-02 — v4.1.2 – Chat low-power optimization, persistent window minimization & fullscreen behavior

• Reduced Chat synchronization to 10% frequency when Low Power Mode is active while the Chat window is closed.
• Reduced Chat packet size to 25% and packet rate to 25% during closed-window Low Power Mode operation.
• Added additional Low Power Mode performance optimizations to reduce unnecessary rendering, timers, polling, and background work so games can run as smoothly as possible.
• Fixed Chat ping banners so they can remain visible over fullscreened applications through the fullscreen notification layer.
• Added a minimize button to all application windows, positioned to the left of the refresh button.
• Changed window minimization so minimizing an app no longer closes its iframe or navigates it to about:blank; the application continues running while minimized.
• Added a dedicated minimized-application tray above the Start button that appears only when applications are minimized.
• Added square minimized-app buttons matching the launcher applet style, displaying the first letter of each minimized application's name.
• Added clickable minimized-app tray buttons that restore their corresponding application windows.
• Kept the minimized-app tray separate from the taskbar while visually attaching it above the taskbar.
• Made the minimized-app tray remain above floating windows but not above fullscreened applications.
• Added Start-menu-aware tray positioning so the minimized-app tray moves to the right when the Start menu is opened.
• Added automatic fullscreen Low Power Mode handling for non-Chat application windows while preserving the user's previous Low Power Mode state.
• Restored the previous Low Power Mode state when a fullscreened application exits fullscreen or its window closes.

2026-10-02 — v4.1.1 – Chat sync throttling, fullscreen low-power behavior & persistent ping banners

• Reduced Chat synchronization to half rate whenever Low Power Mode is active or the Chat window is closed, including 25-message sync batches, doubled batch spacing, halved manifest entry payloads, doubled manifest debounce/minimum timing, and slower periodic manifest broadcasts.
• Restored full Chat synchronization rate when the Chat window is open and Low Power Mode is not active.
• Reduced Chat PING frequency from 5 seconds to 10 seconds while Low Power Mode is active, including when the Chat window is closed.
• Added parent activity-state reporting so Chat can react immediately when the Chat window opens/closes or Low Power Mode changes.
• Added automatic Low Power Mode activation while any non-Chat application window is maximized/full-screened, while preserving the previous Low Power Mode state after the window is restored or closed.
• Ensured restored desktop window state also reapplies the fullscreen-triggered Low Power Mode behavior correctly.
• Raised the Chat ping-notification banner above maximized/full-screened application windows so ping alerts can still pop down over other apps.

2026-09-30 - v4.1.0 - Storage optimization, performance improvements, expanded themes & chat resilience

• Reworked service-worker caching to prevent unnecessary persistent Cache Storage writes on ordinary page loads and avoid repeatedly rewriting the main document.
• Reduced persistent cache growth by limiting cached resources by type and size, excluding large game/preview assets from the core cache, and removing obsolete Arcade Hub cache snapshots during service-worker activation.
• Added bounded, compressed chat-history persistence using browser compression APIs where available with LZString fallback.
• Added automatic chat-history compaction and configurable retention windows, with support for Forever, 7-day, 30-day, and 90-day history retention.
• Added configurable chat-history storage modes for Text Only, Attachments, and Full Media.
• Added automatic lossy image compression for oversized chat images and size-bounded handling for videos, voice recordings, and other attachments to reduce persistent storage usage while retaining chat media.
• Added a unified Storage Manager to System Monitor covering Cache Storage, IndexedDB/localForage, localStorage, sessionStorage, and estimated overall origin usage.
• Added per-category browser-storage cleanup controls and lightweight storage diagnostics to identify persistent storage consumers.
• Added Low Power Mode with reduced decorative effects, paused hidden applets, visibility-aware timers, reduced polling/presence activity, capped large-grid rendering, and other optimizations for older or resource-constrained devices.
• Added visibility-aware rendering and image decoding improvements to reduce unnecessary work for hidden or off-screen content.
• Added session/layout restoration, desktop layout profiles, recent-project history, favorites organization, crash-recovery state, and settings import/export support.
• Expanded the Windows-era visual system with Windows 95 Blue, Windows Gray, Windows 98 Teal, Olive Desktop, Plum Desktop, DOS Amber, Blue-Gray NT, and Midnight DOS theme presets.
• Added theme-specific desktop patterns and wallpaper support while preserving the classic Windows-style UI structure.
• Added more authentic Windows-era interface details including hierarchical Start-menu behavior, classic tooltips, selection states, beveled group boxes, progress indicators, system-tray overflow handling, context menus, Explorer-style address bars, and themed desktop combinations.
• Added optional startup splash and classic system-sound support for startup, dial-up/network, and other desktop events.
• Expanded System Monitor with lightweight diagnostics for browser storage, rendering/performance state, and resource usage.
• Improved Chat persistence and recovery so existing local history is loaded before network synchronization and malformed/legacy stored data does not silently present as an empty chat.
• Added automatic discovery and merging of available GitHub chat-history exports, including export-date tracking so newer discovered backups can be merged without replacing existing history.
• Preserved existing MQTT chat functionality while improving durable history handling, media storage, and recovery behavior.
• Improved Chat connection-state handling and resilience around reconnects, presence, online-user tracking, and administrative functionality.
• Added safer handling for persisted chat state so pending DMs, tombstones, settings, and other non-history data cannot be incorrectly compacted as message history.
• Optimized repeated audio notification handling by reusing a shared AudioContext instead of creating a new audio context for every notification.
• Reduced unnecessary browser work during repeat visits and background operation while retaining existing applets, games, CRT functionality, and other site features.
• Fixed persistent-storage growth caused by redundant cache writes and duplicated cached Arcade Hub data.
• Fixed chat-history loading and recovery paths that could make previously stored conversations appear to have disappeared.
• Fixed chat initialization paths so persistent history recovery does not prevent the MQTT connection from being established.
• Fixed theme persistence and switching behavior so desktop backgrounds, title bars, and other themed surfaces can change independently without altering the classic Win95-style blue header and launch-button treatment.
