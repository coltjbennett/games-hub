CONTROL PANEL
Windows-era appearance, storage-safe desktop behavior, and session controls. Preferences stay in this browser.

Appearance

GAMES HUB
Low Power Mode keeps features but disables decorative CRT/shadows/marquee work, pauses nonessential hidden applets, and reduces background polling.

Desktop session

The desktop remembers window positions and visible applets. Game windows remain on Recent Projects rather than forcing games open.

Theme packs

Packs include the theme, CRT, motion, compact, contrast, and power settings.

Convenience

Keyboard shortcuts: Ctrl+K or / opens Quick Launch. Esc closes it.

Local library data

Favorites and recent-project history are browser-local and separate from chat data.

Reset

Reset only launcher appearance/preferences. Chat history, username, and game saves are left alone.
