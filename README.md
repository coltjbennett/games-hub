# games-hub
a hub and launcher for games, made by me, Colton Bennett. it has a universal MQTT chatroom, a ton of in-house games, and it looks really cool.

## the site is live!
check it out here:
[https://coltjbennett.github.io/games-hub/](https://coltjbennett.github.io/games-hub/)


## included
The launcher is a static GitHub Pages site with in-house games, desktop-style applets, and a small browser-based MQTT chat system. The [change log](./CHANGELOG.txt) records launcher and architecture updates.
