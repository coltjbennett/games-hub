COLTON'S PROJECT LAUNCHER — CHANGE LOG
======================================

v3.1.5 — September 29, 2026

CORE / SHELL
- Added a Windows 95-style Change Log window, opened by the new footer button.
- Added the Web Browser applet to the Start bar/taskbar.
- Tightened parent/child window messaging to accept messages only from the expected same-origin frame.
- Added safer window/app URL handling and a cleaner calculator-specific visual mode.
- Improved taskbar accessibility labels for applets.

CHATROOM
- Added stronger validation for incoming MQTT data and user/session fields.
- Hardened dynamic user-list rendering to avoid building executable inline handlers from remote usernames.
- Escaped dynamic system/message author text before DOM insertion.
- Added bounds on malformed/oversized network payloads and safer decompression handling.
- Added stricter validation for reactions, message IDs, durations, statuses, and sync channels.
- Reduced unnecessary typing/presence traffic and made message publishing fail safely on malformed data.
- Kept the existing client-side admin passcode behavior unchanged.

ARCADE / NETWORKING
- Hardened the repository-driven arcade renderer against unsafe inline event construction.
- Tightened parent activity messaging for the arcade iframe.
- Added safer API-cache parsing/fallback handling.

CALCULATOR
- Reworked the calculator into a more authentic Windows 95-era scientific-calculator UI.
- Removed calculator CRT treatment and ensured its surface uses the normal Windows grey.
- Replaced JavaScript Function() evaluation with a small expression parser, removing the eval-like execution path while retaining scientific operations.
- Added keyboard input support and clearer calculator status feedback.

MAINTENANCE
- Updated visible site version to v3.1.5.
- Updated the homepage last-updated timestamp.
- Corrected several existing copy typos.


=== v3.1.5-hotfix — 2026-09-29/30 ===

SECURITY / RELIABILITY:
- Added schema validation and size limits for incoming MQTT events.
- Sanitized persisted chat history and user lists before rendering.
- Removed network-controlled inline handlers from dynamic game/user/message UI paths.
- Added strict URL-scheme/origin checks for launcher/game navigation and iframe messaging.
- Reduced typing-indicator traffic and bounded local history growth.
- Added safer URL validation to the Web Browser applet.
- Kept the existing admin passcode behavior unchanged.

ARCADE:
- Hardened the GitHub API cache/parser against malformed data and API timeouts.
- Game cards now use DOM event delegation rather than injecting API data into onclick/onerror attributes.
- Added keyboard activation for arcade cards.

CHATROOM:
- Dynamic usernames, reactions, message IDs, media URLs, replies, and activities are now normalized before use.
- User-list and message controls no longer embed remote usernames/message IDs directly into inline JavaScript.
- Large or malformed MQTT payloads are rejected early.

WEB BROWSER:
- HTTP/HTTPS navigation is now parsed and validated before proxy navigation.

- Added bounded MQTT payload validation and normalization to the FPS multiplayer client.
